# weather-app-vibecoded-b01a121e

A vibe coded weather app with [Lovable.dev](https://lovable.dev/)

Technologies: 
- React/Tanstack Start
- Tailwind CSS
- Shadcn
- OpenMeteo API

To get started locally:
1. Clone the repo
2. Open up a terminal at the repo root, run `npm i` to install necessary dependencies.
3. Run `npm run dev` to start the application locally.
